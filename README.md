## About this mod

Moar Concrete 9minecraft Mod finishes a job vanilla Minecraft left half done. Concrete arrived as sixteen clean, flat colours and nothing else - no stairs to cap a roof, no slabs to break up a floor, no fence to run along a terrace. Build anything more detailed than a cube and you have to switch to stone halfway through and lose the colour. This adds the missing shapes, in every colour, so a build can stay one material from the foundation to the ridge.
